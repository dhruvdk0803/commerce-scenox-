Wix Stores is built for simplicity, and its import reflects that: a fixed set of columns, rules about how variants are written, and little tolerance for improvisation. A supplier spreadsheet rarely fits it without rework.

## What you get

- A Wix-ready product file built from your supplier data
- Product names, descriptions and ribbons written or cleaned to one style
- Product options and variants structured so each choice has its own price or stock where needed
- Collections assigned so your store menu and filters work
- Images matched to products and loaded by URL
- Prices, SKUs, weight, inventory and visibility settings checked
- SEO titles and descriptions prepared for the product pages
- A QA report of anything changed or flagged

## How it works

1. You send your files and tell us how many products and how many images you expect.

4. We import products as hidden, through a collaborator account you control. You review in your dashboard.
5. You approve, we make them visible, and you keep the final file.

## Wix Stores details we plan around

### The CSV layout

The Wix import template has a column for the product handle, a field type that marks a row as a product or a variant, and columns for name, description, price, SKU, inventory, weight and visibility. Options use paired columns for the option name, type and values. We build to the template as it stands in your dashboard, and test a small batch first, because Wix can change its import format.

### Product options

Wix supports a limited number of options per product, and a variant row must reference option values that exist on the parent. If a source product has more attributes than Wix allows, we choose which become options and which move into the description or an info section. Colour options can be shown as swatches, which needs the colour values to be consistent.

### Collections

Collections are named groups products are assigned to. In the import file a product can reference the collection it belongs to. If names differ by a capital letter or a trailing space, you get duplicate collections, so we normalise them first.

### Images

Wix pulls images from URLs. The links must be public and stable, and the files should be sensibly sized, or the import will be slow or skip them. We host or organise images where needed, match by SKU, and confirm the main image of every product.

### Batching

Large catalogs are safer imported in batches, so an error in one file does not stall the whole job. We split by category or supplier and check each batch before the next.
